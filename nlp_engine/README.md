# NLP Engine (Member 1 Workspace)

## Responsibilities
Member 1 owns the development, evaluation, and serving of the NLP Engine:
1. **Language & Script Detection**: Identify source language and Romanized code-mixed text (e.g., Hindi written in Latin script `hi-Latn`).
2. **Preprocessing Pipeline**: Clean text, normalize colloquial spelling variations, handle emojis/punctuation.
3. **Complaint Categorization**: Classify complaints into the 6 standard categories:
   - `water_supply`
   - `road_damage`
   - `garbage`
   - `drainage`
   - `streetlight`
   - `other`
4. **Confidence Calibration**: Provide a reliable `category_confidence` score and trigger `requires_human_review = True` if confidence < 0.65 or if category is ambiguous.
5. **Summarization**: Produce a concise, standard English summary for administrative action.
6. **Duplicate Detection**: Compare candidate complaints against existing complaints using semantic similarity embeddings.

## Module Structure
- `constants.py`: Holds exact category IDs and system thresholds.
- `schemas.py`: Pydantic models enforcing the standard output contract (`NLPAnalysisResponse`).
- `pipeline/`:
  - `preprocessor.py` (to be created): Text cleaning and script detection.
  - `classifier.py` (to be created): Categorization model.
  - `summarizer.py` (to be created): Extractive/abstractive summary module.
  - `deduplicator.py` (to be created): Vector similarity against open complaints.

## Contract Verification
All outputs generated by any module must strictly validate against `schemas.NLPAnalysisResponse` as defined in `docs/api_contract.md`.
