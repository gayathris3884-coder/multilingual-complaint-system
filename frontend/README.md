# Frontend Application (Member 2 Workspace)

## Overview
Built with **React** and **Vite**, using a modern Vanilla CSS design system. It powers:
1. **Citizen Portal**: Accessible grievance submission with language input tips and real-time tracking.
2. **Municipal Admin Dashboard**: Triage board for municipal department officers to review, filter, and resolve complaints.

## Getting Started
```bash
# Navigate to frontend
cd frontend

# Install dependencies
npm install

# Start development server
npm run dev
```
The app will be available at `http://localhost:5173`.
All requests to `/api` are automatically proxied to the backend at `http://127.0.0.1:8000`.
